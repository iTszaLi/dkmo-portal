# DKMO Portal – Legacy Member Import System (Production Ready)

I have uploaded a legacy member database (TXT file containing tab-separated member records). Build a complete production-ready import system that safely migrates this data into the DKMO Portal database.

## Goal

The import system must be fast, secure, intelligent, and capable of importing thousands of members with minimal manual work.

---

# Create New Module

**Admin → Data Management → Import Members**

Only Super Admins can access this page.

# Database Mapping

Import into the DKMO Member table.

Map fields as follows:

Legacy ID → legacyMemberId

Application Number → applicationNumber

Old Application Number → oldApplicationNumber

First Name + Last Name → fullName

Mobile Number → mobile

WhatsApp Number → whatsapp

Iqama Number → iqamaNumber

Passport Number → passportNumber

Home Place → nativePlace

Local Place → currentLocation

Date of Birth → dateOfBirth

Jamaath → jamaath

Group → group

Ignore NameAll because it is only a searchable concatenated field.
