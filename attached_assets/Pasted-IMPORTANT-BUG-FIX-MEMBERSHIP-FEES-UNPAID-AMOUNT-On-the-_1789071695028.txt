IMPORTANT BUG FIX — MEMBERSHIP FEES UNPAID AMOUNT

On the Payments → Membership Fees page, when a member is shown under the "Unpaid" status, the membership fee must show SAR 100.00, NOT SAR 0.00.

I can currently see an example:

Yousuf Addoor
ID: DKMO-1182
Status: Unpaid
Fee: SAR 0.00

This is incorrect.

==================================================
CORRECT BUSINESS RULE
==================================================

DKMO membership registration fee is a ONE-TIME fee of:

SAR 100.00

Therefore:

If a member is classified as UNPAID for membership:

Fee = SAR 100.00
Amount Due = SAR 100.00

If the member is PAID:

Fee = SAR 100.00
Status = Paid
Paid On = actual payment date

If there is genuinely no membership fee obligation/evidence for a legacy member, follow the existing evidence-based legacy rules and do NOT incorrectly classify missing information as unpaid.

IMPORTANT:
Do not treat a missing legacy ledger value as automatically unpaid.

==================================================
SUMMARY CARDS
==================================================

The Membership Fees page currently shows:

Paid: 1100
Unpaid: 1
Overdue: 0
Amount Due: SAR 0.00

If there is 1 genuine unpaid membership fee, the dashboard/card must show:

Unpaid: 1
Amount Due: SAR 100.00

If there are 2 unpaid members:

Amount Due = SAR 200.00

If there are 10 unpaid members:

Amount Due = SAR 1,000.00

Formula:

Amount Due = number of genuine unpaid membership fees × SAR 100

Do NOT calculate unpaid amount from an existing zero-valued payment record.

FRF CONNECTION
==================================================

Therefore:

Membership unpaid
→ Membership fee due = SAR 100
→ Membership not fully paid
→ FRF inactive/not eligible

Membership paid
→ Membership fee paid
→ FRF eligibility can become active according to the existing FRF rules
