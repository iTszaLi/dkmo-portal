Build a complete FRF Membership Drive, Recruitment Leaderboard, Momento Award System, Application Timeline Tracking, Reporting, Notification, and PDF Generation module integrated into the existing DKMO/FRF platform.

OBJECTIVE
Create a referral-driven FRF Membership growth system that rewards members for recruiting new members, tracks referrals, maintains application and claim timelines, generates PDFs, provides leaderboards, award management, reports, and automated notifications.

====================================================
1. FRF MEMBERSHIP REFERRAL SYSTEM
====================================================

Enhance FRF Membership Applications to include:

Referral Information:
- Referred By Member Name
- Referrer DKMO ID
- Referral Date

Referral Tracking Fields:
- Total Referrals
- Approved Referrals
- Pending Referrals
- Rejected Referrals
- Current Referral Points

Business Logic:
- When a new FRF application is approved:
  - Automatically increment Approved Referrals for the referring member.
  - Increase referral points.
- When application is pending:
  - Count as Pending Referral.
- When application is rejected:
  - Count as Rejected Referral.

Points System:
- 1 Approved FRF Membership = 1 Point
- System must allow future configurable point rules.
