1. Upcoming Events Widget

---

* Position directly below the Top 5 Recruiters section.

  * Event Name
  * Event Date

  * Event Location

  * Countdown (Today, Starts Tomorrow, Starts in X Days)

* Entire widget must be clickable.
* Clicking an event opens the full Event Details page.
* Include a "View All Events" button linking to the Events module.

Visual Indicators:

* Highlight events occurring within the next 7 days.
* Show "No Upcoming Events Scheduled" if no future events exist.

Data Source:

* Pull data only from the existing Events module.
* No hardcoded or demo data.
* Automatically refresh when events are created, edited, or deleted.

Responsive Design:

* Fully responsive for desktop, tablet, and mobile.

2. Top Sponsors & Collection Responsibility Widget

---

Placement:

* Directly below the Upcoming Events widget.

Purpose:

* Provide visibility into sponsorship commitments and accountability for collections.

Show:

* Sponsor Name
* Sponsorship Amount
* Amount Collected
  transfer method: bank transfer/cash/cheque
* Outstanding Balance
* Collection Status
  (Collected / Partial / Pending)
* Assigned Committee Member Responsible for Collection

Example:

Bank transfer
SAR 10,000
Collected: SAR 8,000
Balance: SAR 2,000
Assigned To: Fazlurrahman Kolkar
Status: Partial

Features:

* Sort sponsors by highest sponsorship amount.
* Display top 5 sponsors by default.
* Include "View All Sponsors" button.
* Clicking a sponsor opens the sponsor profile.
* Clicking the assigned committee member opens their member profile.

Dashboard Summary:
At the top of the widget display:

* Total Sponsorship Committed
* Total Sponsorship Collected
* Outstanding Sponsorship Amount

Data Source:

* Pull directly from the Sponsors module.
* Use actual sponsor and collection records.
* No demo or placeholder values.

Responsive Design:

* Fully responsive across all screen sizes.
