Build a complete production-ready “DKMO Sponsors Management System” (admin dashboard web app) for managing sponsorships, payments, events, staff responsibilities, and reporting for an events organization in Riyadh.

This system must function like a lightweight CRM (Salesforce-style) but simplified for internal DKMO executive use.

────────────────────────────
1. AUTHENTICATION SYSTEM
────────────────────────────

Create a secure login system (NO Google login).

Users (hardcoded or database seeded):

- admin1 / dkmo@2026 → Role: Admin
- finance1 / dkmo@2026 → Role: Finance Team
- finance2 / dkmo@2026 → Role: Finance Team
- event / dkmo@2026 → Role: Event Manager
- user1 / dkmo@2026 → Role: Viewer

After login, redirect users based on role.

────────────────────────────
2. ROLE-BASED ACCESS CONTROL (RBAC)
────────────────────────────

Implement strict role permissions:

✔ Admin
- Full system access
- Add/edit/delete sponsors, payments, events, users
- Assign staff to sponsors
- Access all reports and settings

✔ Finance Team
- View all sponsors
- Can add/edit payments only
- Cannot delete sponsors or users
- Cannot modify roles or system settings

✔ Event Manager
- View sponsors and events only
- Can assign sponsors to events
- Cannot edit payments or delete data

✔ Viewer
- Read-only access to everything

IMPORTANT:
- Restrict editing and deleting actions to Admin only
- Protect all routes using authentication middleware
- Block unauthorized URL access
- Hide UI buttons based on role
