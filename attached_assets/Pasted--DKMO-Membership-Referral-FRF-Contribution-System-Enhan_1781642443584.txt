# DKMO Membership, Referral & FRF Contribution System Enhancement

After reviewing the Members, Membership, FRF, and Referral workflows, I would like to restructure the system so that membership fees, referrals, and FRF contribution collections are fully connected.

## 1. Remove Monthly Dues Completely

The current "Monthly Dues" concept is incorrect and should be removed everywhere.

Remove:

* Monthly Dues column
* Monthly Dues reports
* Monthly Dues dashboard widgets
* Monthly Dues calculations
* Monthly Dues statistics

DKMO does not have a monthly membership fee.

---

## 2. Replace With One-Time Membership Fee

Every member pays a one-time registration fee of:

**100 SAR**

Add a new column in Members:

| Member | Reference Member    | Membership Fee | Fee Status | Actions |
| ------ | ------------------- | -------------- | ---------- | ------- |
| Ahmed  | Fazlurrahman Kolkar | 100 SAR        | Paid       | ...     |

Fee Status options:

* Paid
* Pending
* Unpaid

Admin actions:

* Mark as Paid
* Mark as Pending
* Mark as Unpaid

Store:

* Amount
* Status
* Payment Date
* Updated By

---

## 3. Reference Member Column

Add a new column immediately after Member:

**Reference Member**

This should display the member or committee member who referred the applicant.

The reference member selected during application should remain permanently linked to that member profile.

---

## 6. Follow-Up Responsibility System

This is extremely important.

The member who referred a new member should be responsible for following up with them regarding payments.

Under every Reference Member dashboard create:

### Members Under My Referral

Show all members referred by that person.

For each member display:

* Member Name
* Mobile Number
* Membership Type
* Membership Fee Status
* FRF Contribution Status
* Last Payment Date

## 10. FRF Contribution System

FRF is not a monthly fee.

When an FRF member passes away and a claim is approved:

Automatically create an FRF Contribution Cycle.

Contribution amount:

**50 SAR per active FRF member**

Example:

Claim:
Mohammed Ali

Contribution:
50 SAR

Eligible Members:
850

Expected Collection:
42,500 SAR

## 12. Referral-Based FRF Collection Follow-Up

The most important enhancement:

For every FRF Contribution Cycle, the Reference Member should be able to see which of their referred members have not paid the 50 SAR contribution.

Example:

### Members Requiring Follow-Up

Ahmed
Reference: Fazlurrahman Kolkar
FRF Contribution: 50 SAR
Status: Unpaid

Saleem
Reference: Fazlurrahman Kolkar
FRF Contribution: 50 SAR
Status: Pending

This allows committee members and referrers to actively follow up with the members they brought into DKMO.
